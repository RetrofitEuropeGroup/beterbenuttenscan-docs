# beterbenuttenscan-docs

## Lokaal uitvoeren

Installeer de documentatie-dependencies en start de lokale server:

```shell
pip install -r requirements.txt
mkdocs serve
```

Open daarna `http://127.0.0.1:8000/`. De map `/beterbenuttenscan-docs/` hoort bij de GitHub Pages-publicatie en wordt niet gebruikt als lokaal URL-prefix door `mkdocs serve`.
