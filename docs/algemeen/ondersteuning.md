# Ondersteuning

Het gebruik van de scan wordt op verschillende manieren ondersteund.

## Snelle volger programma
Als gemeente kan je je aanmelden als snelle volger. De scan wordt dan voor jullie werkgebied klaargezet om zelf, ondersteund door deze handleiding, mee aan de slag te gaan. De gemeente kan dan zelf de scan uitvoeren en de resultaten gebruiken.
